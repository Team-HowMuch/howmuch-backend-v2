시연 운영 가이드

시나리오를 고르고 ‘새 그룹으로 준비하기’를 누르면 실제 개발 서버에 새 그룹과 미납 정산이 생성됩니다. 폰에서 그룹 목록을 새로고침하세요.

편집·복제·삭제는 서버에 저장됩니다. 정산마다 생성자와 참여자를 지정할 수 있습니다.

그룹 관리에서 전체 선택 후 삭제할 수 있습니다. 압축 진행 중인 그룹은 제외하며 정산·입금·압축 기록은 보존합니다. 삭제한 그룹은 이 화면에서 복원할 수 없습니다.

통신이 끊겼다면 ‘작업 결과 확인’으로 같은 요청을 재확인하세요.
