# 은행 인증 수준 전환 선행 호환 reader

- 관련 이슈: #542, 후속 PR #543
- 목적: V54의 데이터 전환 전에 배포할 롤백 기준 버전을 제공한다.
- 스키마 변경 및 Flyway migration: 없음. 이 PR은 V54을 포함하지 않는다.

## 동작

기존 v2 API·Boolean 응답·ID/PW 지원 은행 목록을 유지한다. 계좌 자격정보가 필요한 기존 은행은 Boolean 시기의 `1` 및 수준 시기의 `3`을 모두 읽는다. 기존 ID/PW 목록 밖 은행의 새 `1`은 공동인증서 전용이므로 계좌 정보를 요구하지 않는다.

## 배포 순서 및 제한

1. 이 호환 reader PR을 develop에 병합하고 dev/prod에 각각 배포한다. 이미지 SHA를 롤백 기준으로 기록한다.
2. 배포 확인 후 #543의 V54 및 v3 구현을 함께 배포한다.
3. 실패 시 V54 적용 전 구버전이 아니라 1단계 호환 이미지로 롤백한다. 데이터는 다시 Boolean으로 되돌리지 않는다.
4. 롤백 기간에는 V54의 초기 은행별 수준 매핑을 운영자가 변경하지 않는다. 새 인증 방식/은행 지원을 관리자로 변경한 뒤 기존 allowlist 기반 이미지로 돌아가는 것은 지원하지 않는다.

## 검증 및 커밋 경계

- 기존 BankCatalog 테스트를 `1`/`3` 양쪽으로 실행하고 공동인증서 전용 은행의 `1`이 자격정보를 요구하지 않는지 확인한다.
- `./gradlew compileJava test --tests '*BankCatalogTest' --no-daemon` 실행.
- `fix(account): 인증 수준 전환 전후를 읽는 호환 reader 추가` 단일 커밋.
